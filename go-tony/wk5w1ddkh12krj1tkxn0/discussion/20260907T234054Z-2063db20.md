Property 1 bounds the TRANSIENT -- a read's working set against the answer's size. The measured store's problem is the FLOOR: index resident 1.12 GB of a 1.31 GB live floor. A read that is out-of-memory by construction on top of an O(history) resident index has bounded the wrong term.

Element identity makes it worse before better. A trie node is not a map entry -- measured on this tree, an EMPTY node is ~4 KB: Index 56 + Tree 16 + node 64 + a preallocated 32-slot leaf at 32 x 120 B. Affordable at 46,836 path nodes; not when a node is an element.
