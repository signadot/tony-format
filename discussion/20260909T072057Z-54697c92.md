THE BAR, from this issue: a store of the staging shape served with a working set set by the
delta and the path, with no heap ceiling configured. Measured on staging at v0.0.207:

    reads.narrow.avg   378ms (pre-rebuild v0.0.205)  ->  22.9ms
    folded per read    25                            ->  12.6
    writes.avg         11.8ms                        ->  13.2ms

reads.wide is 0 throughout -- nothing asks for the root. No whole document is held on any
read or write path: the head is a number, a watch holds the value at its path, and a match
is encoded straight from the cursor. What the index HOLDS is bounded and configurable, and
what it DESCRIBES is still all of history.

SUBSUMED AND CLOSED with this: rkb7p8v5 (a write and every watcher fold the whole document),
thqtmm2t (a keyed element cannot be addressed), rg5nd1ps (state and patch events rooted
differently), qvn7ptxc (index size bound -- answered by bounding residency instead), and
5hmq80f3 (bounded op-preserving scope compaction).

NOT SUBSUMED, still open, and the honest list of what this rebuild did not fix:

  9b2vpggx and sb33w8p9 -- THE SCOPE COST. A scoped read replays the scope's own patches at
  the path from commit 0, and no snapshot shortens it, because snapshotPath reads with
  scopeID nil and path snapshots are baseline's. Re-measured today: a scoped write is
  2.21ms / 3.64 / 7.27 / 14.28 across N=50/100/200/400 prior scope writes, where baseline is
  flat at ~700us. Phase 3b removed the kept scope document that used to make a run of scoped
  writes flat, so the cost is now uniform rather than cheap-until-interleaved. Reshaped, not
  fixed, and it is the one substantial thing left.

  4wpqh7t2 -- ONE STORABLE-DELTA PIPELINE. Not built: a scope still takes claimValue where
  baseline takes storableDelta. It is deliberate and documented -- a scope stores its CLAIM
  because baseline moves underneath it, and a diff would lose the claim -- but the
  unification this issue asks for does not exist.

  mgg9nvt6 -- mergeop's !raw merge semantics, never part of this.
