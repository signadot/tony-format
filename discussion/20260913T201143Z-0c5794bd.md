A precondition is evaluated against what its pattern names: a shape test (!or [{}, !irtype null]) reads the path's kind, a field pattern ({e5: {}}, !not {nope: ...}) reads the named fields, and only a whole-value pattern (an array, !all) reads the value. The kind is decided from the index -- base snapshot's first event, statements at or above the path applied, writes below it not decoded -- with the cursor read as the fallback where the index cannot decide.
