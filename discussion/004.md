Fixed in go-tony v0.0.88 — items 1–4 and 6–8, plus a latent bug found alongside item 7. Item 5 remains open.

Each fix has a round-trip regression test (through generated code where relevant). All 10 codegen packages in go-tony regenerate cleanly, and `o b` on the signadot operator manifests is byte-for-byte identical to v0.0.68.

- **Item 1** (`ToTonyIR` dispatched only for pointers) — `gomap.toIRReflectValue` now checks for `ToTonyIR` on non-pointer values too (value receiver, then `val.Addr()` when addressable), mirroring the existing TextMarshaler handling. This also fixes item 2's reflection path (a named map with a codec is now dispatched to via reflection).
  `commit` gomap: dispatch ToTonyIR for non-pointer values

- **Item 2** (named map type never dispatched — codegen half) — a `Map`-kind field whose named type carries a schema directive now emits `s.Field.ToTonyIR()/FromTonyIR()` instead of inlining the map (which lost the codec and generated invalid Go for the decode). Scoped to `Map`; struct/pointer fields already dispatch and named scalars go by kind.
  `commit` codegen: dispatch a named-map field to its codec

- **Item 3** (unresolvable type → invalid Go) — when go/types reports a field's type as a struct but it resolved to a non-struct reflect.Type (the int fallback), `ResolveFieldTypes` now fails with an actionable message naming the field/type and pointing at the fixes (annotate it, add `codec=custom`, or `omit`), instead of emitting `ir.FromInt` on a struct.
  `commit` codegen: diagnose an unresolvable referenced type

- **Item 4** (annotating to resolve also generates colliding methods) — new directive modifier `codec=custom` (e.g. `//tony:schemagen=leaf,notag,codec=custom`): the type stays collected, resolvable, and schema-generated — so a referencing type calls `s.Field.ToTonyIR(...)` — but its own four codec methods are not generated, leaving the hand-written ones. A package can now mix generated and hand-written codecs. Together, items 2+3+4 resolve the all-or-nothing bind.
  `commit` codegen: add codec=custom marker — resolvable without generating

- **Item 5** (nested calls drop `opts...`) — NOT fixed. Still open. The fix needs the resolver to mark local-generated types, which the placeholder reflect.Type used for source-resolved types cannot currently express.

- **Item 6** (whitespace-only input inconsistent) — every blank body tokenizes to only `TIndent`; `parse.Parse` now short-circuits an all-indent stream to `(nil, nil)`, so spaces, tabs and newlines behave alike (a body of spaces no longer errors with \"extraneous indent\"). The `(nil, nil)` contract for a blank document is preserved intentionally to avoid breaking callers; only the inconsistency is fixed.
  `commit` parse: treat any whitespace-only body as a blank document

- **Item 7** (`map[string]any` unsupported by codegen) — an interface-typed map value now emits the reflection path: `gomap.ToTonyIR(v, opts...)` to encode and `gomap.FromTonyIR(v, &val, opts...)` to decode. Also fixed `getQualifiedTypeName` spelling an anonymous interface as the invalid \"interface\" (→ `interface{}`).
  `commit` codegen: support map[string]any via the reflection path

- **Item 8** (named scalar resolves to int) — `resolveASTType` recovers the underlying basic kind from go/types for a named non-struct scalar (e.g. `type Verb string`), so codegen emits the right conversion; `generatePrimitiveToIR` casts to the builtin (`ir.FromString(string(v))`), and the FromIR slice path converts back to the named element type (`slice[i] = Verb(elem)`). Named scalars as map values or as a top-level slice type are not yet covered.
  Side effect: this corrected a latent bug in go-tony's own generated schema — `SessionRequest.Migration` (`*MigrationAction`, a named string) was described as `int`; it is now `string`.
  `commit` codegen: resolve named scalar types by underlying kind

- **Latent bug (found alongside item 7)** — a bare `interface{}` field generated calls to `toIRInterface`/`fromIRInterface`, which are defined nowhere; any struct with such a field produced uncompilable code. Now dispatches through `gomap.ToTonyIR`/`FromTonyIR`.
  `commit` codegen: dispatch interface{} fields through the reflection path

Note on the item-4 suggestion \"skip generation for any type that already declares the methods\": implemented as the explicit `codec=custom` modifier rather than automatic detection, so the opt-out is visible in the source and can't silently mask a wanted regeneration.
