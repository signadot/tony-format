## 19. `omitzero` is ignored by codegen for a field whose type implements `MarshalText`

Against **v0.0.113**. Sibling of item 12 (`omitzero` on a struct-valued field): the option is
consulted on some branches of the generated encoder and not on others, and the TextMarshaler
branch is one of the ones it is not.

```go
//tony:schemagen=verse-pattern,notag
type Pattern struct {
    System string   `tony:"field=system"`
    Kind   string   `tony:"field=kind,omitzero"`
    Op     Op       `tony:"field=op,omitzero"`      // type Op string, with MarshalText/UnmarshalText
    Predicate *ir.Node `tony:"field=value,omitzero"`
    At     []string `tony:"field=at,omitzero"`
}
```

Generated encoder — `Kind`, `Predicate` and `At` all honour the option, `Op` does not:

```go
    // Field: Kind
    if s.Kind != "" {
        irMap["kind"] = ir.FromString(string(s.Kind))
    }

    // Field: Op
    if txt, err := s.Op.MarshalText(); err != nil {
        return nil, fmt.Errorf("failed to marshal field %q: %w", "Op", err)
    } else {
        irMap["op"] = ir.FromString(string(txt))       // <- no emptiness test
    }
```

So every encoded Pattern carries `op: ""`, whatever it was tagged with. The reflection path
gets this right — `isZeroForOmit` (`gomap/to.go`) ends in `v.IsZero()`, which is true for a
defined string type — so the two paths disagree about the same struct, which is the shape
item 15 is also about.

**Cost to verse:** cosmetic only, and no workaround applied. An `entity.Pattern` is what an
external source declares as the slice its reflection is complete for, and what a source
registration carries as `owns` (docs/working/sources.md); the stray `op: ""` is noise in
those documents but decodes back to the empty Op it was, so nothing is lost. Dropping the tag
would have been worse: `Op` would then not round-trip at all, and a local source and one
reached over HTTP would disagree about a diagnostic. Pinned in verse at
`entity.TestPatternSurvivesTheWire`, which logs when the field starts being omitted so the
note explaining it can go.
