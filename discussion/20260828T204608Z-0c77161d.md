# checkStorableInScope after lowering: the wrinkle, measured

Raised in review of the lowering worktree, and correct. Measured:

```
!replace   baseline   ACCEPTED   lowering stores it as  s: rob
!replace   scope      REFUSED at NewPatcher, before lowering runs
!rename    baseline   ACCEPTED   lowering stores it as  t: bob
!rename    scope      REFUSED at NewPatcher
plain data both       ACCEPTED
```

So the same operation is now accepted in baseline and refused in a scope, and the
reason given for the refusal is one lowering has removed:

> a scope's base moves as baseline advances, so an operation whose meaning depends on
> what was there cannot be stored in one

That was about what gets STORED. With lowering the relative operation is never stored:
it is applied at the write and the RESULT diffed. The premise is gone.

The ordering is why the refusal still fires -- `NewPatcher` runs `checkUnsafeWrite`,
`checkStorableInScope` and `checkArrayWrite` before the commit path is reached, and
`lowerWrite` is inside `WriteAndIndex`. So the refusal is not merely stale, it is
upstream of the thing that made it stale.

## a consequence worth stating plainly

**Lowering currently does nothing for scopes.** The only writes that would need it are
refused at the door, so `NeedsLowering` never answers yes for a scoped write, and the
scope path stores exactly what it always did.

Which also bounds the evidence: `TestHeadEquivalence`, `TestReadEquivalence` and the
three-row matrix all commit with `NewTx(1, nil)`. Every number behind turning lowering
on -- 11 failing tests to 0, 24 dropped-at-snapshot to 0, 150 clean seeds -- is
BASELINE evidence. The scope path has none of it, because there is nothing there to
measure yet.

## what removing the refusal needs

1. That a scoped relative write, lowered, survives a moved baseline -- the exact
   failure `3xn08cb6h12kr4psg5n0` records, where a stored `!replace` made the scope
   unreadable from the next baseline write onward and `DeleteScope` was the only
   repair.
2. A scoped differential of its own, the equivalent of the matrix, since the existing
   one cannot see the scope path at all.

Both are the same piece of work and it is the natural next one: lowering makes the
repair 3xn08cb6 asked for possible, and the refusal is what stands in for it today.
