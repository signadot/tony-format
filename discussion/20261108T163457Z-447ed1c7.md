bd291a42 also mixes the counter. `NewXID` now stores `mixCounter(c)`, a bijection on 24 bits (xorshifts and multiplies by odd constants), and the test checks it over all 2^24 values. The pid mask is now keyed on the stored counter. With both changes, the first 8 characters of the XIDR vary from id to id, e.g. `vyr709wr…`, `redydz30…`, `ycts5m8e…`. Only the machine id (`h12k…`) and the timestamp stay fixed, and those come after character 8.

Cost: ids that one process mints within the same second no longer sort in the order they were made. Nothing depends on that order: production code uses only the XIDR, which never sorted in creation order.
