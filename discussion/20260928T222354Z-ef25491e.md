From the tony-format side: option (1), progress on request, is being implemented under gkmdvps7h12ksvf8q9n0, on branch `worktree-issue-gkmdvps7`.

The shape is `progress: {path, watchId?}`, naming a watch the way `unwatch` does. The answer is `result: {progress: {path, commit: C}}`, where C is the head when the request was handled. It is sent from the watch's own goroutine after every event that watch sends for a commit ≤ C. If the watch ends first, the request gets `not_watching`. docd routes `progress` by path. A watch docd composes across mounts is refused with `unsupported` for now.
