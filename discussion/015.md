Cross-package references fixed in 3a115bb (with 7e9c9ac regenerating stale testdata fixtures alongside).

The mapper built every reference as `filepath.Base(pkgPath) + ":" + strings.ToLower(typeName)` and returned it without checking that such a schema exists, or asking what it is called. Three of the five references in this repo pointed at nothing:

| emitted | target declares |
|---|---|
| `time:duration` | nothing at all |
| `tx:state` | `//tony:schemagen=tx-state` |
| `aliastarget:format` | an alias; the target declares `aliastarget-real` |

The two that worked did so by coincidence: `api.Patch` happens to declare `patch`, and `format/format.tony` happens to be named for its Go type.

Resolution now comes from what the target declares — its schemagen directive or marker field, read from the target package's own source so both spellings work; failing that, a hand-written `.tony` beside its sources publishing that name (the only link those have to a Go type). Aliases resolve to what they name first, in whichever package that lives, which is **item 14 seen from the schema side**. When nothing is found, no reference is emitted: it falls through to the field's text marshaling, then the underlying kind.

That ordering also corrects a mistake in afacf92. Putting the TextMarshaler check ahead of everything degraded `dirbuild`'s `format` field from `format:format` — an enum of `tony|yaml|json` in `format/format.tony` — to a bare `.[nullable(string)]`. True, but strictly weaker. A resolvable reference is both precise and true, so it goes first; text marshaling is what to say when there is nothing to point at. Restored.

`TestGeneratedSchemasHaveNoDanglingReferences` walks every committed `schema_gen.tony` and checks each reference against what the target package publishes — 23 references today, all resolving. Run against the previous commit's schemas it reports all three dangling references above. Nothing else would: a wrong schema breaks no build and no round-trip.

Both fixes are in `gomap/codegen/crosspkg.go` and the reordered branches in `GoTypeToSchemaNode`, which now reads: target's own schema → TextMarshaler string → underlying kind.
