Two corrections to the comment above, from building it.

**The ping's `floor` is not the replay floor.** It is the oldest commit a watch starts from as asked: the commit a read at the replay floor is answered at. Every commit from there on is read exactly. A relative cursor is clamped to it, in logd and in docd (which resolves a relative cursor from the ping), so a relative cursor always lands on a commit it can start from, with or without `noInit`.

**Through docd**, a composed watch with a cursor reads its state before it starts its sub-watches, and starts them from the commit that state was answered at. Two cases don't move:
- `noInit` with an absolute cursor is refused with `replay_compacted`, as logd refuses it. With `waitIfAbsent` as well, docd reads no state, and the refusal is logd's own, passed on under logd's code.
- A cursor below the replay floor is refused as before.
