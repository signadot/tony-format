Scope decision: DROP problem #3 (Watch-declining ErrUnsupported mount poisoning overlapping composed watches). Making docd composition treat an ErrUnsupported-from-Watch mount as 'contributes no events' would have docd paper over a controller's declared behavior, violating the thin fail-fast proxy design. The controller-side workaround (a blocking no-op Watch that emits nothing until ctx cancel) is the intended pattern and keeps that boundary clean.

Remaining scope: #1 (replace the fixed 5s force_after guillotine with backoff + a graceful membership update that does NOT end overlapping readers) and #2 (surface the ended-at Commit so a genuinely-ended watch — e.g. controller_unavailable — can resume gaplessly via FromCommit). #1's graceful path subsumes #2 for the membership_changed case (no end -> no gap); #2 remains for the crash case.
