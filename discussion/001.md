## Implemented (0ac7428)

CAS is now reachable end to end, and a latent tx-layer bug was fixed in the
process.

Bug: evaluateMatches (tx/match.go) matched the pattern against the raw ReadStateAt
result, which is rooted at the document root; the read/match path extracts the
value at the path first (extractPathValue) but the tx match did not — so a pattern
written against the value never matched real state. It passed unit tests only
because their mock CommitOps returns bare leaves (not rooted docs) and no test
covered a successful match. Fixed: evaluateMatches navigates to the value at the
match path before comparing.

Wiring: api.PatchRequest.Match (regen); handlePatch passes it to the patcher;
libctl PatchIf/PatchTxIf with sentinel ErrMatchFailed; docd threads Match to
controllers via PatchParams and maps a controller's ErrMatchFailed back to
match_failed. Match path may differ from patch path.

Tests (race-clean): CAS success / failure / cross-path against real logd; CAS
routed through docd to a controller.
