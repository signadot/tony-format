-m Prerequisite 4 drafted: go-tony/system/logd/storage/docs/one_delta_shape.md (ee7c589). All four are now on paper.

The shape is not new -- storableDelta is already the one function (b39eca8). The statement is that its output is the ONLY delta: stored, replayed, notified, delivered are the same bytes.

The divergence today is conditional, which is worse than constant: the notification is built from the client's merged patch before the write, and NeedsLowering decides whether the log keeps something else. So the shape a watcher sees depends on what some other client wrote.

Four changes: notification derived from the stored entry; NeedsLowering may survive as an optimisation but not as a condition on shape; one rooting rule by the read's own projection (rg5nd1psh12kse7dddn0); and !logd-patch-root deleted -- it is a genuine stored-vs-delivered difference, it already produced xmxt2p85h12ksjp1gsn0, and the index answers what it answers once a commit's segments are its touched paths.

Two dependencies on prerequisite 3 worth noting. Lowering needs base and next, verifyApplies supplies whole documents, and there is no stepped head any more -- so lowering is per path, which is sound only because an op's effect stays under the node it tags. patchMayAffect names !key and !arraydiff as the exceptions; identity removes the first and makes the second the array's own business. And the keyed fallback in scopeHasKeyedPaths / readScopedStateAtOverlay / lowerWrite goes because there is no undeclared keyed array once the schema is the authority -- "the last thing standing between a scope and being ordinary", removed by prerequisite 3 rather than by scope code.
