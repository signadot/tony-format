Step 3 (Watch composition) design — contract pinned.

DECISION: watch-event delta Patch rooting is canonically ROOT-ROOTED (absolute
from document root), matching what raw logd emits; ev.Path only identifies the
watch. Forced by switchability (a client must not tell docd from logd). Init
State stays relative (the subtree at the path), as logd does.

Consequence: controllers must emit root-rooted deltas. The controller runtime
forwards handler events verbatim, and the reference memController currently emits
RELATIVE deltas — it (and the controller watch contract doc) will be corrected as
part of this work. This also fixes an existing base-vs-mount rooting inconsistency
clients already see today.

Composed watch on P (MountsUnder(P) non-empty), given root-rooted deltas:
1. Register the coordinator reader at P (already wired) so membership is fixed for
   the watch's life.
2. docd synthesizes ONE client watch confirmation (WatchResult{Watching:P}).
3. Emit one composed initial State event at P = composed Match(P) (unless NoInit).
4. Establish NoInit sub-watches, intercepting their deltas: base owner (logd over
   a dedicated streaming connection, or the owning controller) + each mount below
   P. Each intercepted delta is forwarded with Path re-stamped to P; the patch is
   already absolute so it passes through unchanged (no nesting).
5. Teardown on unwatch/close/force: stop every sub-watch.

Build units: MountSession streaming-watch route (events -> docd handler, not the
client); dedicated logd streaming-watch connection; composed-watch manager;
memController root-rooted correction; then membership_changed + LogdSession
auto-re-watch across force AND crash.
