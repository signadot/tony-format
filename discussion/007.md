## Revision to D1 (comment #004) — docd defaults direct to logd for base paths

D1 concluded docd is a pure router (no direct logd data path; a passthrough controller
required for raw logd-backed data). Revised: docd defaults to talking DIRECTLY to logd
for base/unmounted paths. Fewer hops, and you get a working document store with zero
controllers.

### Layered model (filesystem-like)
- Base document lives in logd. docd serves base/unmounted paths directly against logd:
  match, patch, watch, plus tx coordination.
- A controller MOUNT overlays a subtree. Ops under a mount route to that controller
  instead of logd (owner-served; content may not be in logd — the connect-controller
  case).
- Longest-prefix decides: path under a registered mount -> controller; else -> logd.

This matches the Plan 9 framing in design.md: a real root store with special sources
mounted at paths. The mounted-content-through-controller conclusion (earlier point 2 /
comments #001, #003) is UNCHANGED — that is the overlay case. Only the base case changes.

### What this revises
- docd is NOT a pure router. It keeps a real logd client for reads/writes/watches on
  base paths (component D's watch handling returns, scoped to base paths). The #004
  "cut M1 scope: docd needs no logd read/watch path" note is partially reverted: docd
  needs the logd data client for base paths.
- The old tonyapi "controllers are the ONLY components talking to logd" was already
  softened (docd requests tx IDs); this relaxes it further, deliberately, for fewer hops.
- The passthrough controller is demoted from required plumbing to a worked EXAMPLE for
  controller authors (better as documentation than as a mandatory hop).
- docd <-> logd stays wire (#006) — unaffected.

### Improved M1 build order
- M1a: docd as a transparent logd proxy on the client face (forward match/patch/watch
  to a LogdSession). Instantly proves switchability: point a LogdSession at docd,
  reads/writes unchanged, near-zero code.
- M1b: add mount registry + route mounted subtrees to controllers; unmounted still hits
  logd directly.
