Item 16 (the `ir.Node.Hash` fix): the hash was built on a seedless `maphash.Hash`
that took a fresh random seed per instance, so `n.Hash()` drifted every call and
the doc comment claiming stability was exactly wrong; a second bug computed the
comment hash but never wrote it into the hasher. Rewritten on `fnv.New64a()` —
deterministic across calls and processes, comments now folded in — with tests.

Every fix has a cross-path regression test; all codegen packages regenerate cleanly;
the logd/docd wire api changed only for WatchEvent.EndReason (10A, the documented
omit); the operator build (o b) is byte-identical throughout.
