Decided (Scott): an operand path that names nothing, or names something that isn't a number, is an **error**, the same rule `!get-path` keeps everywhere. Not a no-match.

So an operand that cannot be compared against is always an error: a literal that isn't a number, a scale that isn't a number, a wild path, a missing path, or a path that names a non-number. The only no-match is a doc node that isn't a number.
