Broader than begin()'s flush: after replay, composedWatch.forward writes each sub-watch's live delta as it arrives (watch.go), so deltas from different mounts reach the client in arrival order, not commit order. WatchEndedError.Commit is then not an exact resume point for a composed watch. The docs state the contract (exact) and cite this issue as the gap (libctl/watch.go, docd/server/doc.go, 3d7t1khx).
