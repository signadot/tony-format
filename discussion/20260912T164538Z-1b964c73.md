docd hop added (c2b583d1): a retain is routed rule by rule to the owner of its container, logd or the controller whose mount holds it, one request per owner with one now for all. The result answers the rules in the order sent, each with owner, under (mounts beneath the container the rule did not reach) and error (what the owner said if it refused). A controller that does not implement retain answers unsupported, which is reported per rule; the request is an error only when nothing ran anywhere. Nothing is composed beneath a container. libctl gets LogdSession.Retain.
